D'asaro — Esquema de Arquitectura

Diagramas de sistema, jerarquía de módulos y relaciones de dominio para el ecommerce de vitaminas y suplementos, con énfasis en los dos módulos diferenciales: la Encuesta de Recomendación Nutricional y el Portal Educativo.

Proyecto: farmacia_app / D'asaro Versión: v1 — diseño Fecha: 2026-08-31 Formato: 4 láminas, Mermaid
Flujo núcleo (catálogo, órdenes, pagos) Flujo diferencial (encuesta ↔ educativo)

01 — Arquitectura de sistema

LÁMINA 01 / 04

Punto de entrada único vía Nginx (TLS), API FastAPI como backend único, Redis como cache y broker del worker asíncrono, y los webhooks de las pasarelas de pago entrando por el mismo borde que el resto del tráfico.

02 — Jerarquía de módulos y carpetas

LÁMINA 02 / 04

El backend se organiza por capa (rutas → servicios → modelos) y, dentro de cada capa, por módulo de negocio. core/ es la base compartida (seguridad, cifrado, cache) que todos los servicios consumen.

03 — Relaciones de dominio

LÁMINA 03 / 04

Las flechas gruesas marcan el enlace diferencial: el resultado de la encuesta recomienda productos y artículos, y cada artículo puede enlazar de vuelta a productos y a las reglas de recomendación que lo originaron.

04 — Flujo diferencial: encuesta → recomendación → contenido

LÁMINA 04 / 04

El recorrido de negocio que sostiene el diferencial: el portal educativo no solo informa, reenvía al usuario a la encuesta; y la encuesta no solo vende, también educa.
